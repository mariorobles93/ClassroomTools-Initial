Import CSV

Your CSV file should contain one barcode per row using the following columns:

barcode,name,companion,status 10000001,John Smith,None,valid 10000002,Jane Doe,Michael,valid 10000003,Robert Johnson,None,used

Column Information

  • barcode - numeric barcode value
  • name - person's name
  • companion - companion name or "None"
  • status - either valid or used

Importing a CSV will replace the current code list. Existing data will not be deleted until the import is successfully processed.
