Number Base Converter

Convert an integer between decimal (base 10), octal (base 8), hexadecimal (base 16), and binary (base 2). The page also shows the repeated-division method used to calculate the answer by hand.

For hexadecimal, A–F represent the values 10–15. You can enter letters in either uppercase or lowercase.

Manual division procedure

To convert a whole number to base 16, repeatedly divide by 16. Record each remainder, then read the remainders from bottom to top.
